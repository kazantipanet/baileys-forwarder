# AITube WhatsApp Baileys Forwarder

Автоматичний пересилач повідомлень між групами WhatsApp на базі Baileys, із вебінтерфейсом керування та LLM-фільтрацією AITube V2.

## V1 — класичний forwarder

Базова версія проєкту забезпечує:

- підключення до WhatsApp через QR-код;
- отримання списку груп;
- правила пересилання між групами;
- декілька правил одночасно;
- увімкнення, призупинення та видалення правил;
- локальний вебінтерфейс;
- журнал пересилань і статистику;
- захист від дублювання повідомлень;
- автоматичне перепідключення;
- запуск на Android через Termux.

## V2 — LLM template-only filter

V2 додає контрольований LLM-фільтр перед пересиланням повідомлень.

Потік обробки:

```text
WhatsApp message
       ↓
LLM classification
       ↓
template + variables + confidence
       ↓
confidence check
       ↓
required variables check
       ↓
render approved template
       ↓
SEND / SKIP
```

Ключовий принцип V2: **LLM не генерує довільний текст для відправлення.** Повідомлення може бути відправлене тільки після вибору існуючого шаблону та успішної перевірки необхідних змінних.

Повідомлення отримує `SKIP`, якщо:

- шаблон не знайдено;
- confidence нижче порогу;
- відсутня обов'язкова змінна;
- немає достатньої інформації для безпечного рендерингу шаблону.

Типовий поріг confidence: `0.85` (може бути налаштований через `LLM_CONFIDENCE_THRESHOLD`).

## Шаблони

У production можна використовувати приватний файл:

```text
private/templates.json
```

Каталог `private/` виключений із Git і призначений для робочої конфігурації.

Для відтворюваного тестування в публічному репозиторії використовується:

```text
llm/templates.json
```

Публічний файл містить лише sanitized/test шаблони та не є заміною приватної production-конфігурації.

## Налаштування

Створіть `.env` на основі власної конфігурації:

```env
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-5
LLM_CONFIDENCE_THRESHOLD=0.85
```

Не публікуйте API-ключ, WhatsApp session/auth files або production-конфігурацію шаблонів.

## Запуск

Встановлення залежностей:

```bash
npm install
```

Запуск застосунку:

```bash
npm start
```

Локальний вебінтерфейс:

```text
http://127.0.0.1:3000
```

Після першого запуску відскануйте QR-код у WhatsApp через **Пов'язані пристрої**.

## Тести

Основний V2 regression test:

```bash
npm test
```

Тест перевіряє вибір шаблонів, вилучення змінних, confidence та обов'язковий `SKIP` для нерелевантних/неповних повідомлень.

Також окремі тести знаходяться в `llm/`.

## Android / Termux

Для Android використовується Termux:

```bash
bash install.sh
bash start.sh
```

## Безпека

Не комітьте:

- `.env` та `.env.*`;
- `auth_info/`;
- `private/`;
- локальні журнали;
- локальні налаштування та файли стану.

Ці файли виключені через `.gitignore`.
