# AITube WhatsApp Baileys Forwarder

Open-source застосунок для автоматичного пересилання повідомлень між групами WhatsApp із вебінтерфейсом керування правилами.

**Проєкт AITube**

## Можливості

- підключення до WhatsApp через QR-код;
- автоматичне отримання списку груп;
- створення та редагування правил пересилання;
- декілька правил одночасно;
- увімкнення та призупинення правил;
- видалення правил;
- вебінтерфейс керування;
- журнал пересилань;
- статистика;
- захист від дублювання повідомлень;
- автоматичне перепідключення до WhatsApp;
- запуск на Android через Termux.

## Технології

- Node.js
- @whiskeysockets/baileys
- Express
- Pino

## Android / Termux

Для Android використовується Termux. Базова схема встановлення:

```bash
bash install.sh
bash start.sh
```

Після першого запуску відскануйте QR-код у WhatsApp через **Пов'язані пристрої**.

Вебінтерфейс локального запуску:

```text
http://127.0.0.1:3000
```

## Безпека

Файли авторизації WhatsApp (`auth_info/`), журнали та локальні налаштування не повинні публікуватися в репозиторії. Для цього вони виключені через `.gitignore`.
